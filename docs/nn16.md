# SFNNの16bit重みモデルを使う

BulletOuの`export-nn16`で書き出した`nn16.bin`を使うには、SFNNのビルド時に
`ENABLE_SFNN_16BIT_WEIGHT`を定義します。通常の`nn.bin`をリネームするだけでは使えません。

```sh
make normal -j4 \
  YANEURAOU_EDITION=YANEURAOU_ENGINE_SFNN_halfka2_1024_8_64_progress8 \
  TARGET_CPU=AVX2 COMPILER=g++ \
  EXTRA_CPPFLAGS=-DENABLE_SFNN_16BIT_WEIGHT \
  OBJDIR=obj-nn16 TARGET=YaneuraOu-nn16
```

別のビルドとオブジェクトファイルを共用しないでください。
`EvalDir`に`nn16.bin`を置きます。progress付き構成では同じフォルダに対応する
`progress.bin`も必要です。

エンジンに送るコマンド例:

```text
usi
setoption name EvalDir value /path/to/eval
setoption name FV_SCALE value 24
bench 64 1 100000 default nodes
quit
```

`FV_SCALE`はモデルに合った値を指定してください。16bit化による倍率変更は内部で補正するため、
従来の8bitモデルと同じ値を使います。

このシンボルを定義しないビルドは、従来どおり8bit重みの`nn.bin`を使います。

## ファイルと計算

- version: `0x7AF32F17`、モデルhash: `0x3C203B32`。
- description直後のuint32が量子化倍率QB。64以上16384以下の2のべき乗を読み取ります。
- FTは従来形式。L1/L2/L3はint32 biasとint16 weightで、入力幅を32単位にパディングした行優先形式です。
- FC積和はint64。二乗活性化は飽和を先に判定してオーバーフローを防ぎます。
- QB=4096ならCReLUのシフトは12、SqrCReLUは31です。負の入力も二乗します。
- shortcutがあればL3に加算し、`QB / 64`で割ってから従来の`FV_SCALE`を適用します。
- FCは16bit専用の積和ループを使います。8bit用SIMDカーネルと同じ探索速度を保証するものではありません。

整数演算の回帰テスト:

```sh
python3 -m unittest discover -s tests -p 'test_sfnn16.py' -v
```
